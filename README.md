# Meipuratchi — React (Exact Original Output)

`home.html` is the main page and opens first.

The original HTML/CSS/JavaScript is kept as the visual source inside `public/`, while React/Vite provides the application shell. This is intentional so the screen output remains the same as the supplied website rather than becoming a redesign.

## Run
npm install
npm run dev

Open the Vite URL, usually http://localhost:5173

## Main page
http://localhost:5173/home.html

The other original pages are available under `/india/`, `/tamil_nadu/`, and `/global/`.
